# 單字延伸推薦

每個單字（含使用者自訂字）都能透過 `WordExtensionService.recommend` 查詢。
結果可能只有例句，或完全為空；不要求每個字都有相關字與易混淆字。

## 依據與排序

1. `word_relation_data.dart` 的明確關係：雙向查詢，但兩端釋義必須對應。
2. 字典釋義明載的變化形，例如 `fly 的過去式`：確認原形與變化形都存在於字庫，兩端詞性合理，且目前卡片符合該變化形註記的義項與詞性。
3. 否定前綴線索：non-/un-/in-/im-/il-/ir-/dis- 拆出的原字與原單字都須為字庫中的形容詞，
   且中文釋義能以「不／非／無／沒有／不是」明確對應。可雙向查詢，不列作易混淆字。
4. 字庫的多字詞條：含完整原字，且中文釋義含目前義項（至少兩個中文字）。
5. 合寫複合字線索：目前單字為名詞，兩段英文各至少三個字母且都存在於字庫並有可用例句。
   只推薦名詞組件，且組件中文釋義須出現在原字釋義中；一字釋義須在開頭或結尾。
   例如 windmill（風車）可找到 wind（風），不會單憑拼字把 carpet 拆成 car/pet 推薦。
6. 相同詞性、相同完整中文釋義：只標示「字庫釋義同為…」，不宣稱能互換或屬同一字族。
   比對前移除句尾標點；形容詞另正規化末尾的「的」，例如「不重要。」與「不重要的」。
   長說明中的逗號碎片不視為獨立釋義；短列舉的義項須有候選例句佐證。查證提示不作為詞義證據。

自動候選需有 twCeec/pdfExamBook 來源，並有國小／國中或難度 1–4 的依據；
未標程度字僅可經明確整理關係、或有常用原形佐證的變化形進入。古語、方言、
生僻與明示外語詞等候選排除。新增常用字關係有雙端詞性與對應義項例句，
例句須仍是字庫中的原文。

同級候選先考慮基礎教材依據，再依原字程度距離、字母順序排序；相關字最多三個，易混淆字最多兩個。
去除重複、原字本身、無可用雙語例句、空釋義、明顯 HTML/wiki 污染，以及人名等泛稱釋義。
易混淆字只取明確關係資料；不由拼字相似、共同標籤或共現例句推測。

## 用法與複習

用法優先使用義項相符的整理內容，並補充目前單字的雙語例句。
目前單字無可用例句時，只在釋義對應時取用字庫例句。
例句沒有頻率資料，因此畫面標為「用法例句」，不宣稱是常見搭配。
新增相關字沿用字庫的釋義、詞性、可用例句與現有複習排程，來源標為內建字庫。

## 載入與限制

展開「延伸學習」才載入字庫。服務由 `main.dart` 注入，首次以字庫 repository
共用快取建立索引，同時查詢共用同一個 Future；失敗可重試。之後直接查索引，
不逐次掃描全字庫。索引分批讓出執行緒以保持載入畫面的回應。
編輯單字、詞義、詞性或例句後，畫面清除舊結果，下次展開重新查詢。

首次展開需要讀取 26 個分片並增加記憶體使用量，低階裝置仍需實機評估。
既有字庫含多義或品質不一的內容，精確釋義比對會保守漏掉同義但不同寫法的關係；
也無法保證字庫每句例句都精確對應目前義項。擴充明確關係資料時應同時補上兩端義項與測試。
