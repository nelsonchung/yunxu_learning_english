# 更新已加入複習的字庫內容

內建字庫與個人複習卡片各自儲存。新版 App 的字庫修正不會自動覆寫既有卡片；使用者可先比對，再選擇套用，無須刪除重加。

## 操作

1. 開啟內建來源的單字卡，選擇「比對字庫內容」。亦可從單字列表的「檢查字庫更新」入口檢查多張卡片。
2. 中文意思選擇保留、使用字庫內容或自行編輯。自行編輯時可帶入字庫解釋再調整。
3. 例句選擇保留、全部取代或保留原句並加入選取的字庫例句。補充不會自動移除舊錯句，請檢查最後清單。
4. 查看套用結果，確認後更新同一張卡片。預設保留目前內容，沒有實際變更時不寫入。

## 資料保護

- 僅修改使用者選取的意思、例句或詞性，以及 `updatedAt`。
- 保留 ID、建立時間、排程、歷史、評級、下次複習日期與已掌握狀態。筆記、標籤與圖片亦保留。
- 預覽後若只發生複習，套用時保留最新進度。若英文、意思、例句或詞性改變，拒絕舊預覽並要求重新比對。
- 更新與同步／還原互斥。寫入失敗不更新記憶體卡片，可再次嘗試。
- 精確比對僅忽略英文首尾空白及大小寫；沒有唯一詞條時不套用，不猜測詞幹、同義詞或改名。

## 字庫版本與界線

「目前字庫」指已安裝 App 所附的 assets，並非線上即時字庫。開發機修改 JSON 後，其他裝置需安裝包含修正的新版本。

既有卡片沒有原始字庫快照，不能可靠判斷差異是字庫修正或個人修改。因此使用者選擇要採用的內容，並且畫面使用「不同」而非宣稱字庫一定較新或較正確。

比對提供字庫完整例句，包含早期加入流程只取前兩句而未帶入的其他例句；原本的新增流程不受影響。

本機更新保留最新複習進度。跨裝置離線同時修改的衝突，仍依既有的整卡 `updatedAt` 策略處理；本功能沒有新增欄位合併或改變 iCloud 協議。
